# Mnemonic Generator

A lightweight CLI tool written in TypeScript for generating cryptocurrency wallets and mnemonics across multiple blockchain networks without requiring clipboard access—ideal for use in restricted environments like Termux or GrapheneOS Terminal.

## Purpose

This tool addresses a critical workflow issue: generating wallet mnemonics in sandboxed or restricted terminal environments where clipboard functionality is unavailable or blocked. Instead of relying on clipboard utilities, this tool generates a file with mnemonic and other essential data for accessing a wallet, allowing you to avoid traceable identifiers (like Telegram login requirements in Metamask) when creating anonymous cryptocurrency wallets.

**Supported Networks:**
- **XMR** (Monero)
- **BTC** (Bitcoin)
- **ETH** (Ethereum)
- **SOL** (Solana)


## Usage

### Generate a Mnemonic and Wallet Address

```bash
pnpm run generate --network <coin> --mnemonic_size <size>
```

### Options

| Flag | Alias | Type | Default | Description |
|------|-------|------|---------|-------------|
| `--network` | `--coin`, `-c` | STRING | — | The cryptocurrency network to generate an address for (xmr, btc, eth, sol) |
| `--mnemonic_size` | `--size`, `-ms` | NUMBER | 12 | The number of words in the generated mnemonic (12, 15, 18, 21, or 24) |
| `--help` | `-h` | — | — | Display help information |

### Examples

Generate a 12-word BTC mnemonic and address:
```bash
pnpm run generate --network btc
```

Generate a 24-word Ethereum mnemonic and address:
```bash
pnpm run generate --network eth --mnemonic_size 24
```

Generate a Solana wallet with a 15-word mnemonic:
```bash
pnpm run generate -c sol -ms 15
```

Generate a Monero wallet with default settings:
```bash
pnpm run generate --network xmr
```

## Output

The tool outputs:
- **BIP39 Mnemonic** – The seed phrase for wallet recovery
- **Derived Address** – The public wallet address for the selected network

All output is printed directly to the terminal for copy-paste into restricted environments.

## Security Considerations

⚠️ **Important:** This tool is designed for local development and testing only.

- **Do not use mnemonics generated by this tool for storing real cryptocurrency funds** without thorough security audits
- Generated mnemonics are output to the terminal; ensure your terminal session is secure
- Consider using air-gapped machines or Tails OS for production wallet generation
- Always back up mnemonics securely (encrypted storage, physical backup)
- Never share mnemonics or private keys with anyone

## Troubleshooting

### Command not found

Ensure you're running the command from the project directory where `package.json` is located.

### Clipboard errors

This tool intentionally avoids clipboard operations. If you see clipboard-related errors, they can be safely ignored—output is always printed to terminal.

### Invalid network name

Double-check the network flag uses lowercase: `btc`, `eth`, `sol`, or `xmr`.
